# Домашний бюджет

Мобильное приложение для учёта доходов, расходов, лимитов и целей накоплений.
Expo SDK 57 + React Native + TypeScript, навигация на Expo Router.

## Запуск

Нужен Node.js 20.19+ (проверить: `node -v`).

```powershell
cd C:\Users\Anna\home-budget
npm install          # только первый раз
npx expo start
```

Дальше один из вариантов:

- **На телефоне.** Установите приложение **Expo Go** (App Store / Google Play), телефон и компьютер — в одной Wi‑Fi сети. Отсканируйте QR-код из терминала: на Android — из Expo Go, на iPhone — обычной камерой.
- **В браузере.** Нажмите `w` в терминале — откроется http://localhost:8081.
- **В эмуляторе Android.** Если установлен Android Studio, нажмите `a`.

Если телефон не подключается (корпоративная сеть, VPN), запустите `npx expo start --tunnel`.

Код обновляется на лету: сохраните файл — приложение перезагрузится само.

## Что умеет

- **Главная** — общий баланс, доходы и расходы за месяц, прогресс бюджета и сумма «можно тратить в день», счета, последние операции.
- **Операции** — поиск, фильтр «все / расходы / доходы», переключение месяцев, группировка по дням. Тап по операции — редактирование или удаление.
- **«+»** — быстрый ввод: расход или доход, сумма, категория, счёт, дата, комментарий. Последние категория и счёт подставляются автоматически.
- **Статистика** — кольцевая диаграмма по категориям (тап по сегменту или строке выделяет категорию), доходы и расходы за полгода, расходы с начала месяца против равномерного плана, автоматические подсказки.
- **Бюджет** — лимиты по категориям (тап — изменить), цели накоплений с пополнением со счёта и расчётом «сколько откладывать в месяц», сброс и загрузка демо-данных.

Данные сохраняются на устройстве (AsyncStorage). При первом запуске загружаются демо-данные за последние полгода — их можно очистить на вкладке «Бюджет».

## Анимации

Всё на встроенном `Animated` из React Native, без дополнительных нативных модулей, поэтому работает в Expo Go и в браузере:

- появление карточек и списков при каждом открытии вкладки;
- «бегущие» суммы баланса и остатков;
- заполнение полос прогресса;
- прорисовка кольцевой диаграммы, рост столбцов, прорисовка линии;
- скользящие индикаторы у переключателей и нижней панели;
- пружинное нажатие кнопок и плиток, «тряска» поля при ошибке ввода;
- сдвиг экранов при переключении вкладок, модальные окна снизу;
- вибро-отклик на телефоне (expo-haptics).

## Структура

```
src/
  app/                 экраны (каждый файл — маршрут Expo Router)
    (tabs)/            вкладки: index, operations, stats, budget; add — место под кнопку «+»
    transaction.tsx    модальное окно операции (создание и редактирование)
    limit.tsx          лимит категории
    goal.tsx           новая цель / пополнение цели
  components/          UI, анимации, графики, нижняя панель
  data/                типы, категории, демо-данные, хранилище и расчёты
  utils/               форматирование денег и дат, вибро-отклик
  theme.ts             светлая и тёмная палитры
```
