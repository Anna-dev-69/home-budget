# Домашний бюджет

Мобильное приложение для учёта доходов, расходов, лимитов и целей накоплений.
Expo SDK 57 + React Native + TypeScript, навигация на Expo Router.

## Запуск

Нужен Node.js 20.19+ (проверить: `node -v`).

```powershell
cd C:\Users\Anna\home-budget
npm install          # только первый раз
npx expo start
```

Дальше один из вариантов:

- **На телефоне.** Установите приложение **Expo Go** (App Store / Google Play), телефон и компьютер — в одной Wi‑Fi сети. Отсканируйте QR-код из терминала: на Android — из Expo Go, на iPhone — обычной камерой.
- **В браузере.** Нажмите `w` в терминале — откроется http://localhost:8081.
- **В эмуляторе Android.** Если установлен Android Studio, нажмите `a`.

Если телефон не подключается (корпоративная сеть, VPN), запустите `npx expo start --tunnel`.

Код обновляется на лету: сохраните файл — приложение перезагрузится само.

## Что умеет

- **Главная** — общий баланс, доходы и расходы за месяц, прогресс бюджета и сумма «можно тратить в день», счета, последние операции.
- **Операции** — поиск, фильтр «все / расходы / доходы», переключение месяцев, группировка по дням. Тап по операции — редактирование или удаление.
- **«+»** — быстрый ввод: расход или доход, сумма, категория, счёт, дата, комментарий. Последние категория и счёт подставляются автоматически.
- **Статистика** — кольцевая диаграмма по категориям (тап по сегменту или строке выделяет категорию), доходы и расходы за полгода, расходы с начала месяца против равномерного плана, автоматические подсказки.
- **Бюджет** — лимиты по категориям (тап — изменить), цели накоплений с пополнением со счёта и расчётом «сколько откладывать в месяц».
- **Счета** — создание и редактирование карты, наличных или другого счёта с фактическим начальным остатком.

Моковых финансовых данных нет: первый запуск начинается с пустой базы. Все счета, операции, лимиты, цели и пополнения сохраняются в локальной SQLite-базе. Интернет для ведения бюджета не нужен.

## Offline-веб и Vercel

Production-сборка является устанавливаемым PWA. SQLite работает в браузере через WebAssembly, а Workbox service worker кеширует оболочку приложения для повторного запуска без сети.

```powershell
npm run build:web
npx vercel --prod
```

Vercel использует `vercel.json`: собирает `dist`, включает необходимые SQLite-заголовки `COEP/COOP` и перенаправляет маршруты в SPA. После первого открытия сайта онлайн его можно установить через меню браузера и далее запускать offline.

## GitHub Pages

Пуш в `main` (и ручной запуск workflow) собирает сайт и публикует его Actions-деплоем. Адрес: https://anna-dev-69.github.io/home-budget/

Один раз в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Workflow пробует включить Pages сам (`enablement: true`), но штатный `GITHUB_TOKEN` не может создать сайт — этот переключатель обычно нужно выставить вручную.

Сборка Pages задаёт `EXPO_BASE_URL=/home-budget`, поэтому подпуть попадает только в этот артефакт. Локальная и Vercel-сборки без этой переменной остаются на корне домена; `vercel.json` не меняется.

GitHub Pages не умеет отдавать `COOP`/`COEP`. Синхронный мост `expo-sqlite` требует `SharedArrayBuffer`, поэтому тот же Workbox service worker добавляет заголовки `Cross-Origin-Embedder-Policy: credentialless` и `Cross-Origin-Opener-Policy: same-origin` и один раз перезагружает страницу. Отдельный COI-worker не регистрируется: у области видимости может быть только один контролирующий service worker. Для прямых ссылок в артефакт кладётся `404.html` (копия `index.html`) и `.nojekyll`.

Важно: данные локальны для конкретного браузера и устройства. Очистка данных сайта удалит SQLite-базу; синхронизации между устройствами без сервера нет.

## Анимации

Всё на встроенном `Animated` из React Native, без дополнительных нативных модулей, поэтому работает в Expo Go и в браузере:

- появление карточек и списков при каждом открытии вкладки;
- «бегущие» суммы баланса и остатков;
- заполнение полос прогресса;
- прорисовка кольцевой диаграммы, рост столбцов, прорисовка линии;
- скользящие индикаторы у переключателей и нижней панели;
- пружинное нажатие кнопок и плиток, «тряска» поля при ошибке ввода;
- сдвиг экранов при переключении вкладок, модальные окна снизу;
- вибро-отклик на телефоне (expo-haptics).

## Структура

```
src/
  app/                 экраны (каждый файл — маршрут Expo Router)
    (tabs)/            вкладки: index, operations, stats, budget; add — место под кнопку «+»
    transaction.tsx    модальное окно операции (создание и редактирование)
    account.tsx        создание и редактирование счёта
    limit.tsx          лимит категории
    goal.tsx           новая цель / пополнение цели
  components/          UI, анимации, графики, нижняя панель
  data/                SQLite-схема, типы, хранилище и расчёты
  utils/               форматирование денег и дат, вибро-отклик
  theme.ts             светлая и тёмная палитры
```
